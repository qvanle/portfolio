# dalelarroder.com

- **Framework**: Next.js
- **Deployment**: Vercel
- **Styling**: Tailwind CSS
- **Analytics**: LogRocket, Umami, Vercel Analytics, Speed Insights

## Running Locally

```sh
bun install
bun run dev
```

## Environment

Copy `.env.example` to `.env.local` and fill in the analytics variables you use.
